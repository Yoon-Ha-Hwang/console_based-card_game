# Short Description
Column Battler is a console-based game where player compete against Intellisense (bot). Players must deploy their cards strategically to win.

# How to Play
The player and Intellisense will take turns to deploy a card at a column of their liking (the player goes first).
<ul></ul>
Deploying a card increases the sum of the total value of cards in the column. The side that has a greater total in a column wins the column.
<ul></ul>
Each column is worth a specific number of points, and whoever wins the column wins all the points in the column.
<ul></ul>
The game ends when both players have used all their cards. The side that has the most number of points at the end of the game wins.

# About Intellisense
Intellisense uses a "what-if" mechanism and evaluates the gains from adding a card in a specific column. Through this, she plays competitively against players.
